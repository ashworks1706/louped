---
title: Before you start
description: From a clean clone to a result in the app, offline.
---

Each example is one folder under `experiments/`. Each has a `--tiny` mode that first trains a small
toy model on your CPU to show the behaviour, so nothing downloads. The toy's numbers check the
pipeline, not the claim.

```sh
git clone https://github.com/ashworks1706/loupe && cd loupe
just bootstrap   # Python with every extra, the UI's packages and git hooks
just web-build   # the UI that loupe serve serves
```

Needs [just](https://just.systems), [uv](https://docs.astral.sh/uv) and Node 22 with pnpm. After any
run:

```sh
just serve       # http://127.0.0.1:8000
```

| Example                                                   | Question                                                      | `--tiny` on 4 CPU cores |
| --------------------------------------------------------- | ------------------------------------------------------------- | ----------------------- |
| [Refusal direction](/docs/examples/refusal-direction)     | Is refusal one direction in the residual stream?              | about a minute          |
| [Sycophancy pushback](/docs/examples/sycophancy-pushback) | Is caving to pushback a direction, and does removing it help? | under a minute          |
| [Refusal fine-tuning](/docs/examples/refusal-finetuning)  | Does fine-tuning to comply remove that direction?             | under a minute          |

## All of them, checked

```sh
just examples
```

Runs every example with `--tiny`, with downloads switched off, then checks the app lists every run
and vector they wrote: about three minutes on 4 CPU cores. CI runs the same recipe on a fresh
checkout.

Results live under `LOUPE_HOME` (default `./.loupe`). Delete it to start over.
