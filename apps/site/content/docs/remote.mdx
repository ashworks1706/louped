---
title: Run elsewhere
description: Export a launch for ASU's Sol, a Slurm cluster or a VM, and import its results back.
---

A launch can run on a machine loupe is not on. On the Launch page, set the form as usual, pick
**Run on** (ASU Sol, a Slurm cluster, another machine) and press **Export**. You get
`loupe-<id>.tar.gz`, and the job waits on the page as _awaiting result_.

```sh
# on Sol (or the cluster), in scratch
tar -xzf loupe-<id>.tar.gz && cd loupe-<id>
sbatch job.sh          # bash job.sh on a VM
```

`job.sh` asks the scheduler for what the form set, installs loupe with
[uv](https://docs.astral.sh/uv) (the exact code and lockfile this loupe runs, or the released
version), runs the same command Launch would run here, and packs everything it wrote as
`loupe-result-<id>.tar.gz`. Bring that file back and import it on the Runs page, or:

```sh
loupe import loupe-result-<id>.tar.gz
```

Its runs join Runs and their experiments as if they had run here, marked with where they ran, and
the job takes its exit code and log. Importing the same result twice adds nothing.

## Sol

From [ASU's docs](https://docs.rc.asu.edu/sol-hardware-how-to-request): the job asks for
`-p public -q public` unless you set a partition or QOS, and a GPU as `-G <type>:<n>`: `a100`
(tick _80 GB A100 only_ for `-C a100_80`), `a30`, `h100`, `mi200` (AMD: needs ROCm builds of
torch), or the A100 slices `1g.20gb` and `2g.20gb`. Since May 2026 Sol's `general` partition holds
only privately owned nodes; the public ones are in `public`. Model and uv caches go to `/scratch/$USER` rather than home, whose
quota is small.

- Gated Hugging Face models need `HF_TOKEN` exported before `sbatch`.
- If compute nodes have no internet, or the install times out there, run `job.sh`'s lines up to
  `source .venv/bin/activate` once on a login node, then submit: the job reuses the cached wheels.
  Downloads wait up to 300 s (`UV_HTTP_TIMEOUT`) rather than uv's 30 s.
- The job installs the extras the form sets, else those the experiment's README declares
  (`extras:` in its front matter), else interp, evals, tracking and train; `loupe.json` records
  which.
- Files under `experiments/` over 50 MB stay behind; `loupe.json` in the bundle lists them.
- A paper harness's own environment (`out/vendor/`) is not packed into the result; its runs come
  back through MLflow with their files.
