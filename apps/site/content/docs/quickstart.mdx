title: Quick start
description: A result in the app in a few minutes.
---

Every experiment with a `--tiny` mode trains a small model to show the behaviour on your CPU, so
the whole pipeline runs without a download. Its numbers check the pipeline, not the claim.

```sh
just serve   # http://127.0.0.1:8000
```

In the app, open Launch, pick `refusal-direction/run.py`, tick `--tiny` and launch. The job's log
streams in the page and its runs appear under Runs as they write. The same from a shell:

```sh
uv run --all-extras python experiments/refusal-direction/run.py --tiny
```

[Examples](/docs/examples) explains each figure.

## On a real model

Drop `--tiny`. The default, `Qwen/Qwen2.5-0.5B-Instruct`, runs on a laptop; a GPU makes 1.5B and
up practical.

## Your own question

```sh
just new-experiment my-question mechanisms   # experiments/my-question/{README.md,run.py}
```

The README opens with its domain and status, then states the question, what was observed, the
hypotheses, the baseline, the test, when to stop, and the result. `run.py` writes to MLflow and
Inspect logs, so the app shows it and Launch gets a form for its options.
