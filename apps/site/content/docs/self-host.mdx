---
title: Share results
description: Serve the app read-only with Docker.
---

The Docker image serves the app without GPU support. Use it to share results, not to run them.

```sh
docker run -p 8000:8000 -v "$PWD/.louped:/data" ghcr.io/ashworks1706/louped
```

`/data` is the project's `.louped/` folder.

The server has no login. Anyone who can reach it can read every run, so only expose results you
would publish.
