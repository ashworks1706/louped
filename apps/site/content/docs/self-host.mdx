---
title: Self-host the app
description: Run loupe serve in Docker, locally or as a public read-only demo.
---

The image serves the API and the app together. It holds no GPU extras: it reads results written
elsewhere.

```sh
docker run -p 8000:8000 -v "$PWD/.loupe:/data" ghcr.io/ashworks1706/loupe
```

`/data` is `LOUPE_HOME`: point it at the directory your experiments wrote.

## A public demo

`deploy/app` builds the same image with runs baked in, for a read-only app. The server has no
auth: whoever reaches it reads every run, log and transcript, so serve only results you would
publish.

```sh
docker build -f deploy/app/Dockerfile -t loupe-app .
docker run -p 8000:8000 loupe-app
```
